# PRD
Détail d'un besoin du `backlog.md` (racine) : le backlog liste et suit, le PRD spécifie. Un fichier par module, `NNN-<module>.md`, produit par le rôle
`spec-writer` après le cadrage (`grill-with-docs`). Il décrit le QUOI (comportement, contrats, critères CA/CS, sécurité), jamais la structure du code.
