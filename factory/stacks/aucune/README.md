# Stack `aucune`

Squelette sans stack : créer `.factory-verify` (une ligne, la commande de vérification) et ajouter l'installation de l'outil de build au job `verify`.

Fichiers copiés par `./factory/init-projet.sh --stack aucune` (jamais par-dessus un fichier existant) : `.github/workflows/ci.yml`, `.github/dependabot.yml`.
